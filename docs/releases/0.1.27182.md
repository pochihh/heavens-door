# Heaven’s Door 0.1.27182

This release brings together the recent whiteboard, PDF, editor and Settings improvements.

## Whiteboards and navigation

- Add alignment, equal spacing and automatic cleanup for selected elements. Fit cards and boards to configurable S/M/L/XL presets while preserving their relative layout. Auto-height now changes only through its explicit toggle or automatic arrangement.
- New board tiles use the configured M size, with room for six bordered card previews. Board titles edit in place, and board/card emoji appear throughout navigation.
- Home is a regular whiteboard displayed with the workspace name. Breadcrumbs support system pages and document navigation. The last workspace opens at startup.
- Document Tabs actions includes Search tabs, split actions and closing a split. Search results show the active document and its path. Menus dismiss consistently, and interface names follow the documented terminology.
- Improve large-board navigation, image continuity when zoomed out, PDF preview caching and zoom sharpness. Rendering benchmarks retain separate mixed-PDF and no-PDF 10,000-element workloads.

## Cards and PDF attachments

- Make card previews and editors share text wrapping and block spacing. Refine code blocks, checkboxes, image rows and inline code. Add inline math to the selection toolbar and a compact live equation editor for block and inline math.
- Support turning multiple selected blocks into another type, extracting blocks into titled cards with a mention left behind, and a simple card-scoped progress bar.
- Keep PDF controls, pages and comments in one placement layer. Preserve stacking after dragging, resize collapsed cards and PDFs by width, and improve reader interaction and overlapping-note hit targets.
- Extracting a PDF comment keeps its highlight and original note. The note links to the new card, the quote travels with the content, and the mention line starts at the note.
- Keep PDF attachment imports independent from the unfinished Read later feature. Fix tag property/filter separation, and preserve links to source files already inside the workspace.

## Settings and reliability

- Reorganize Settings into grouped cards with clear scope labels, simple controls, editable folder paths, shared accent swatches and consistent command sorting. Settings blocks interaction with the window behind it.
- Add workspace CSS snippets and a computer-wide logo importer with platform-style previews. Generate packaged icons for macOS, Windows and Linux from the branding sources during builds.
- Show recoverable problems in a fixed bottom Context banner with actions, technical details and Copy report. Improve handling of unreadable files, optional settings and indexes without silently replacing source content.
- Stabilize view blocks across split focus changes, widen their horizontally scrollable canvas while retaining default content alignment, and make their actions adapt to narrow views.
- Add native geometry checks for edge labels and expand automated release checkpoints, artifact verification and recovery documentation.

## Known limits

The cached whiteboard renderer remains an experimental option; these changes do not establish a universal frame-rate guarantee for every 10,000-element board. Long save/drop frames and extreme PDF zoom refinement remain areas for further profiling. Windows runtime and Linux appearance have not been verified on this Mac. The downloadable app is not Apple-notarized or Windows code-signed; macOS updater metadata and archives are authenticated separately.

Quit Heaven’s Door Test before opening the same workspace in the regular app. Existing workspaces, card IDs, asset paths and saved interface data are preserved. Test build numbering restarts at Test.1 for this version.
