# Heaven's Door 0.1.2718

This update fixes attachment storage and card-link interactions.

- New external PDF imports now follow the same attachment-folder preference as images and webpage snapshots. The default is `_assets` beside the owning card or whiteboard, such as `Projects/Organizer/_assets`.
- **Settings → Files and folders → Attachments** controls the folder name/path and the choice between local storage and a workspace-level folder. Existing image storage preferences continue to work and now apply to PDFs too.
- Existing asset paths are preserved; changing the setting affects new imports only. PDFs already inside the workspace remain linked in place, including when relinking a missing source.
- Website links in card previews and editors open in the default browser. Right-click a link for Open and Copy link address; internal links also offer Open in new tab.
- Card context menus dismiss when clicking the same card or pressing Escape, including after focus has moved outside the menu.

## Install or update

Quit Heaven's Door Test before opening the same workspace in the installed regular app. In the regular app, choose **Heaven's Door → Check for updates**, or use **Settings → General**. The macOS update uses the existing Sparkle signing key.

Downloads include a universal macOS DMG and a Windows x64 installer. This early release is not Apple-notarized or Windows code-signed. Sparkle authenticates the macOS update feed and archive separately.
