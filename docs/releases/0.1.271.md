# Heaven's Door 0.1.271

An early release for longer testing of the whiteboard, editor, and PDF reading workflows.

- PDF attachments can be read, searched, highlighted, and annotated directly on a whiteboard, with a larger continuous reader in the popup.
- Highlight comments use compact previews and an animated editing sheet. The open comment connects to its highlight with a straight line. Opening a comment preserves the view and scrolls only when needed to reveal it.
- Dragging a comment onto a board creates a normal card, keeps its color, and preserves a link back to the PDF highlight.
- PDF source files already inside the workspace are linked directly; external files are copied into `_assets/`. Missing sources can be relinked from the popup.
- PDF files use the regular multiple-tag and tag-property controls, including `#readlater` status. Tags wrap in the sidebar.
- Standalone whiteboard images and Text elements have compact bounds. Text supports quick branches, keyboard navigation and editing, automatic shape sizing, and conversion into cards.
- Whiteboard elements support copying and applying styles with Command/Ctrl+Shift+C/V. Nearby connectors are easier to find and grab, with zoom-aware visibility.
- Editor improvements include quick code/math blocks, code language selection, consistent font-size presets, and stable nested checkbox and scrollbar layout.
- The updated logo distinguishes the regular app from the orange Test app.

## Install or update

On macOS, use **Heaven's Door → Check for updates**, or the update control in Settings, from the installed 0.1.27 app. The update uses the existing Sparkle signing key. The Test app has a separate identity and does not receive regular updates.

Downloads include a universal macOS DMG and a Windows x64 installer. This early release is not Apple-notarized or Windows code-signed; first-time downloads can show operating-system security prompts. Sparkle update archives and the macOS update feed are authenticated separately.

This is an early testing release. Keep a backup of important workspaces. Do not open the same workspace in the regular and Test apps at the same time.
