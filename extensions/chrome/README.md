# Heaven's Door Capture

1. In Chrome, open `chrome://extensions`, enable Developer mode and choose **Load unpacked**. Select this folder.
2. In Heaven's Door, open **Inbox → RSS feeds → Connect Chrome extension** and copy the connection.
3. Open the extension, expand Connection and paste it. Connect.
4. Save the current page or selected text. Captures enter the paired workspace's Inbox as local Markdown cards with preserved HTML snapshots.

The local queue retries every minute while Chrome is running. Keep the pairing key private. Opening the app and the paired workspace enables delivery. Test and stable apps use different local ports and keys; connect to the app you are testing.

PDF files can be imported directly in Inbox. This extension captures webpages; browser PDF-viewer capture is not implemented.
